# STM32-Nucleo-F103RB-ADC-Based-3-Level-LED-Control
This project demonstrates Analog-to-Digital Conversion (ADC) using the STM32 Nucleo-F103RB. A potentiometer is connected to PA0 (ADC1_IN0), and its analog voltage is converted into a 12-bit digital value. Based on the ADC value, one of three LEDs connected to PA5, PA6, and PA7 is activated, representing low, medium, and high input levels.
